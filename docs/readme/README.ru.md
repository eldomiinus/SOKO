> **«Хаосу традиционного управления запасами здесь больше не место.»** SOKO — это комплексное настольное программное обеспечение, разработанное для начинающих брендов *альтернативной* одежды, шоурумов и текстильных предпринимателей, работающих с ограниченными выпусками или *дропами*. Оно позволяет контролировать полный жизненный цикл каждой вещи с помощью продвинутой системы вариантов, управляя в реальном времени складами, магазинами и временными мероприятиями без потери ни одной единицы товара.

## 🚀 Основные возможности

- **🌐 Динамический мульти-инвентарь:** Создавайте независимые пространства для хранения запасов (Постоянный магазин, Центральный склад, Ярмарки выходного дня). Безопасно перемещайте вещи между местоположениями с помощью реляционных транзакций, а при архивировании временного мероприятия автоматически возвращайте остатки в центральный запас.
- **🧬 Система вариантов (многоуровневая):** Настраивайте «Родительский продукт» и распределяйте инвентарь по каждой комбинации *Размер* и *Цвет* с индивидуальным и точным контролем запасов.
- **🏷️ Генератор этикеток:** Автоматически назначайте SKU для каждого варианта и экспортируйте готовые к печати PDF-шаблоны физических этикеток с соответствующими штрихкодами и ценами.
- **⚡ Массовые действия с каталогом:** Одновременно выбирайте несколько вариантов, чтобы применять процентное повышение цены или изменять операционные статусы (например, с *В производстве* на *Доступен*) одним нажатием.
- **📒 Интегрированный каталог поставщиков:** Внутренняя адресная книга, связанная с технической карточкой, для хранения точных контактов швейных и шелкографических мастерских, соответствующих каждой партии, что жизненно важно для ускорения повторения успешных производств.
- **📉 Отчёт о «залежавшемся запасе» (Dead Stock):** Интеллектуальная аналитическая панель, обнаруживающая вещи, которые находятся без движения на складе более 60 дней, и предоставляющая необходимую метрику для планирования распродаж или специальных акций.

## 🏗️ Архитектура и технологии

> [!NOTE]
> SOKO спроектирован на основе архитектуры **Offline-First**, с приоритетом на нативную производительность, полную переносимость (для бесперебойной работы на ярмарках без подключения к интернету) и абсолютную конфиденциальность локальных данных.

### 💻 Технологический стек

<div align=center>

| Слой | Технология | Описание |
| :--- | :--- | :--- |
| **🎨 Frontend (UI/UX)** | HTML5, CSS3, Vanilla JS | Интерфейс, структурированный с помощью CSS Grid. Нативный дизайн в стиле *Dark Mode* (эстетика *cyber/tech*), окно без рамки (frameless) и динамические сворачиваемые панели. |
| **⚙️ Backend** | Node.js + Electron | Упаковка нативного настольного приложения, обеспечивающая высокую производительность, безопасное управление окнами и глубокий доступ к локальной файловой системе. |
| **💾 База данных** | SQLite3 | Локальный реляционный движок (один файл), размещённый в `userData`. Поддерживает безопасные транзакции ACID и гарантирует переносимость. |

</div>

### 📂 Поток данных и хранение
1. **Реляционная нормализация:** Строгое разделение между идентичностью вещи (общим каталогом) и её физическим местоположением (инвентарями) с использованием транзакционных связующих таблиц (*Inventory_Stock*), полностью устраняющее дублирование данных.
2. **Оптимизированное мультимедийное управление:** Категорически запрещено хранить тяжёлые изображения (BLOB) в базе данных. Фотографии прозрачно копируются в локальный каталог, а SQLite записывает только относительные пути. Это гарантирует, что база данных сохраняет сверхмалый размер и обеспечивает время отклика в миллисекундах.

## 🔗 Модульная экосистема Kyro

SOKO разработан с модульной архитектурой, чтобы стать ядром масштабируемой и настраиваемой рабочей среды, адаптирующейся к операционному и финансовому росту предпринимателя:

- **📦 SOKO (Core):** Основной движок для комплексного управления каталогом, логистикой в нескольких пространствах и исчерпывающего контроля вариантов.
- **🛒 SOKO POS (Расширение кассы — скоро):** Независимый и сверхлёгкий дополнительный модуль, разработанный исключительно для использования за прилавком. Он поддерживает лазерные сканеры штрихкодов и быстро рассчитывает итоговые суммы. Работает как «тонкий клиент», подключающийся к той же локальной базе данных SQLite для списания запасов в реальном времени без необходимости открывать основное административное приложение.
- **📊 KURA (Финансы — скоро):** Финансовая платформа высокого уровня, синхронизируемая для автоматического получения денежных доходов от продаж, зарегистрированных в SOKO/POS, и объединяющая операционный и экономический контроль в одном автоматизированном процессе.

## ⚙️ Установка

Выполните следующие шаги, чтобы запустить среду SOKO на локальном компьютере и начать вносить вклад в разработку.

```bash
# 1. Клонировать официальный репозиторий
git clone https://github.com/eldomiinus/soko.git

# 2. Перейти в корневой каталог проекта
cd soko

# 3. Установить зависимости проекта
npm install

# 4. Убедиться в корректной компиляции нативных модулей (SQLite3)
npm rebuild sqlite3

# 5. Запустить приложение в режиме разработки
npm start
```

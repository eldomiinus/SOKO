> **SOKO** は、独立系アパレルブランド、開発者、技術愛好家のために作られたプロジェクトです。私たちは、経験の程度、性自認、性的指向、障害、容姿、人種、民族、年齢、宗教にかかわらず、すべての人にとって親しみやすく、安全で、歓迎される環境を提供することに尽力しています。

<br>

## 📌 私たちの誓約

開かれた、歓迎される環境を育むために、私たち貢献者およびメンテナーは、プロジェクトとコミュニティへの参加がすべての人にとってハラスメントのない体験となるよう努めることを誓約します。

## ✅ 私たちの基準

前向きな環境づくりに貢献する行動の例には、次のものがあります:

* **歓迎的で包括的な言葉を使うこと:** すべてのコミュニティメンバーとその背景を尊重すること。
* **異なる視点や経験を尊重すること:** 建設的な議論は健全ですが、個人攻撃はそうではありません。
* **建設的な批判を快く受け入れること:** 私たちは皆、学び、よりよいエコシステムを築くためにここにいます。
* **コミュニティにとって最善のことに焦点を当てること:** プロジェクトのアーキテクチャ、セキュリティ、使いやすさを優先すること。
* **ほかのコミュニティメンバーに共感を示すこと:** Discussions で基本的な質問に答える場合でも、複雑な Pull Request をレビューする場合でも。

## ❌ 許容されない行為

参加者による許容されない行為の例には、次のものがあります:

* 性的な表現や画像の使用、および歓迎されない性的な注目や誘いかけ。
* 荒らし行為、侮辱的／軽蔑的なコメント、個人的または政治的な攻撃。
* あらゆる種類の公的または私的な嫌がらせ。
* 明示的な許可なく、住所やメールアドレスなど他者の私的な情報を公開すること。
* 専門的な場において不適切と合理的に見なされうるその他の行為。

## 🛡️ 施行に関する責任

プロジェクトのメンテナーは、許容される行動の基準を明確にする責任を負い、許容されない行為が発生した場合には、適切かつ公正な是正措置を取ることが期待されます。

メンテナーは、この行動規範に沿わないコメント、コミット、コード、Wiki 編集、issue、その他の貢献を削除、編集、または拒否する権利と責任を有します。また、不適切、脅迫的、攻撃的、または有害と判断するその他の行為に対し、貢献者を一時的または恒久的に禁止することができます。

## 📢 問題の報告

虐待的、嫌がらせ的、またはその他の許容されない行為の事例は、GitHub を通じて直接プロジェクトチームに連絡するか、**[kyroshop.exe@gmail.com](mailto:kyroshop.exe@gmail.com)** 宛てのメールで報告できます。 

すべての苦情は確認および調査され、状況に必要かつ適切と見なされる対応が行われます。プロジェクトチームは、事例を報告した人に関する秘密を保持する義務があります。
